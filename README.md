## Funktionen

Das Ticketformular ist eine lokale Demo ohne Versand oder Speicherung. Videos sind als geplante Filmporträts gekennzeichnet. Navigation, FAQ und Inhalte funktionieren auch ohne JavaScript. Die Bildbewegungen berücksichtigen reduzierte Bewegung.
